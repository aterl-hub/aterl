| 核心公式速查

常用化学公式与定律一键查阅

理想气体状态方程

PV = nRT
  • P：压强 (Pa)
  • V：体积 (m³)
  • n：物质的量 (mol)
  • R：气体常数 8.314 J/(mol·K)
  • T：热力学温度 (K)

摩尔质量公式

n = m / M
  • n：物质的量 (mol)
  • m：质量 (g)
  • M：摩尔质量 (g/mol)
  • 数值上等于相对分子质量

物质的量浓度

c = n / V
  • c：物质的量浓度 (mol/L)
  • n：溶质的物质的量 (mol)
  • V：溶液体积 (L)
  • 稀释定律：c₁V₁ = c₂V₂

阿伦尼乌斯公式

k = A·e-Ea/RT
  • k：反应速率常数
  • A：指前因子
  • Ea：活化能 (J/mol)
  • 描述温度对反应速率的影响

化学平衡常数

K = [C]c[D]d / [A]a[B]b
  • 对于反应 aA + bB ⇌ cC + dD
  • 只与温度有关
  • K > 10⁵ 反应基本完全
  • K < 10⁻⁵ 反应难以进行

能斯特方程

E = E° - (RT/nF)lnQ
  • E：电极电势
  • E°：标准电极电势
  • n：转移电子数
  • F：法拉第常数 96485 C/mol
